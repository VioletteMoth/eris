### Overview
ERIS is a command-line text-based Role Playing Game, developped entierly in GOLANG.

---

### Synopsis
In a world not unlike ours, society has developped like a cancer, growing to a point where it has become unstable. \
With the rise of A.I, the Gods that have been left behind start to appear in the capital of the world, Proteus, offering strengh and power for those willing to follow them, increasingly growing at odds with machines and humans for dominion over the world. \
Pick your side between the three factions, and lead the fight to guarantee your emancipation. \
Whatever you are, \
Wherever you are, \
Whoever you are, \
Don't calm down.

--- 

### Installation
Select the `eris.exe` file and press download. Once, dowloaded, open the file to play the game. \
Alternatively, download the `src` folder and at the directory location run:
```
go run .
```
